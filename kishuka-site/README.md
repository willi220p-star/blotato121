# KISHUKA Steam and Clean

Family steam and home cleaning site for Darwin, Palmerston, and rural NT.

## Run locally

```bash
cd kishuka-site
npm install
npm run dev
```

Open http://localhost:5173

## Pages

- Home: offers that scale on hover, looping service cards, steam photos
- Services
- Rates
- Reviews (on-site feedback plus a Google review link)
- Book a clean
- Referral (25% off)

Replace `04XX XXX XXX` and the Google Maps review link once the business profile is live.

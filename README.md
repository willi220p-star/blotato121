# Isha Dhakal · Creator Studio

A creator dashboard for Isha Dhakal. Follower counts are read live from her public TikTok, Instagram, and Pinterest profiles. Photos and videos added in the studio show up on the dashboard, and collaboration notes go to ishadhakal13@icloud.com.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

The public site is [https://willi220p-star.github.io/blotato121/](https://willi220p-star.github.io/blotato121/). A build refreshes the follower counts from TikTok, Instagram, and Pinterest, then publishes the studio. Photos and collaboration notes you add in the browser stay on that device.

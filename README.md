# Pre-sales page template

Send every prospect their own one-page brief the day before the call. Seven sections, one scroll, one button.

This repo is set up for Replit. You do not start from a blank Design canvas.

## Add it to Replit (one click)

The GitHub repo is public, so Replit can import it directly.

1. Sign in at [replit.com](https://replit.com).
2. Open this URL:

   **https://replit.com/github.com/willi220p-star/blotato121**

3. Click **Import**.
4. Click **Run**. The page opens on port 8080.
5. Click **Publish**, pick a subdomain, set access to **Public**, and copy the live URL.

If Import asks which branch to use, pick `main` after this is merged, or the `cursor/presales-replit-template-e8f6` branch until then.

Guided import also works: [replit.com/import](https://replit.com/import) → GitHub → this repository.

## Swap in a new prospect (about 5 minutes)

Edit `config.js` only:

- Company names, hero line, observations, gap, agenda, case studies, CTA
- Point `yourLogo`, `theirLogo`, and `headshot` at files in `assets/`

Then **Run** → **Publish** again (use a new subdomain per prospect, for example `northline-call`).

Do not add sections. Keep this order:

1. Hero
2. What we noticed
3. Where we think the gap is
4. Call agenda
5. Proof
6. Who you are working with
7. CTA

## Optional: restyle in Replit Design

1. In the imported Repl, open **Design**.
2. Fill the brackets in `design-prompt.txt`.
3. Paste that prompt and upload your brand files.
4. When the frame looks right, **Build** it back onto this website, then Publish.

## Send it

Day before the call, not the hour before:

> Hey [name], put together a quick page for tomorrow so you know exactly what we are covering. Takes 2 minutes to skim. [link]
